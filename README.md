# retail-sales-analysis-Dashboard
Retail Sales Analysis using Power BI, Excel and MySQL
## Project Overview
This project analyzes retail sales data to identify sales trends, profitability patterns, customer segments, regional performance, and product performance using Power BI.

## Tools Used
- Microsoft Excel — Data analysis and dashboard creation
- MySQL — Data querying and analysis
- Power BI — Interactive dashboard and visualization

## Project Workflow
1. Cleaned and analyzed the retail sales data in Excel.
2. Created an interactive Excel dashboard to identify sales and profitability trends.
3. Imported the data into MySQL and performed SQL-based analysis using queries.
4. Built an interactive Power BI dashboard for deeper visualization and business analysis.
5. Compared findings across sales, profit, products, categories, regions, and customer segments.
